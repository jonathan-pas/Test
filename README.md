# Simple PWA

Minimale Progressive Web App ohne Abhängigkeiten.

```bash
npm start
```

Dann im Browser öffnen: http://localhost:3000
(anderer Port: `PORT=8080 npm start`)

## Online (GitHub Pages)

Bei jedem Push auf `main` wird `public/` automatisch auf GitHub Pages veröffentlicht:
https://jonathan-pas.github.io/Test/

Einmalig nötig: Repo → Settings → Pages → Source: **GitHub Actions**.
